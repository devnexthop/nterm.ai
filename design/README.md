# Design canvas — nterm.ai

Claude Design canvas for the nterm.ai marketing site. Open `canvas.json` with the
`design` skill to edit the artboards visually.

| File | What |
|---|---|
| `canvas.json` | Canvas definition — 2 pages, 3 artboards, annotations |
| `Main.dc.html` | **Home page** — the deliverable. Editorial frame + live terminal proof block |
| `TerminalNative.dc.html` | Source direction B — terminal-native. Reference only |
| `EnterpriseEditorial.dc.html` | Source direction C — enterprise editorial. Reference only |
| `drafts/nterm-ai-website.html` | Single-file export of an earlier full-site draft |
| `drafts/site-index-draft.html` | Variant of `site/index.html` that diverged from the shipped page |

The shipped site is `site/` at the repo root — that is what deploys. Nothing in
`design/` is served.

Recovered 2026-08-26 from `~/nterm-design/`, a scratch folder that also held a stale
duplicate clone of this repo. The duplicate is gone; this is the only copy.
